# المقاضي والصيدليات

الرئيسية تعرض أزرار «الكل / المقاضي / الصيدليات» فوق البحث. «الكل» افتراضي
للزيارة الأولى؛ يُحفظ القسم المختار محليًا. الروابط المشتركة تنقل القسم
ومصادر البحث، وتغلب تفضيلات المتصفح. الروابط القديمة تُستنتج فئتها من مصادرها.

اختيار المتاجر يفلتر حسب القسم، مع الاحتفاظ باختيارات الأقسام الأخرى. إن دخل
المستخدم قسمًا بلا مصدر مختار، يبدأ بمصادره المتاحة. تغيير القسم بعد البحث
يلغي العرض السابق ويبحث في مصادر القسم الجديد مع منع النتائج المتأخرة من
تغيير البحث الحالي. نافذة الجوال تحتفظ بالتعديل المؤقت حتى الاعتماد.

الافتتاحية تحمل «نفس احتياجك. خيارات أكثر. قرار أوضح.» وتظهر خلال تحميل
الصفحة وتجهيز التفضيلات فقط، بلا مؤقت أو حد أدنى أو زر بدء. وصف الرئيسية:
«قارن أسعار المقاضي ومنتجات الصيدليات، في بحث واحد.»

أول صيدلية: النهدي. تظهر علامة «صيدلية» على عرضها. عبارات البحث تبقى كاملة،
خصوصًا التركيز والعدد. مقارنة الصيدليات تُظهر سعر العبوة والاسم الكامل وتنبه
لمراجعة التركيز والشكل والعدد. لا تُعلن مطابقة علاجية أو أقل سعر وحدة تلقائيًا.
فلتر التوفر يوضح أنه يخفي عروض النهدي ذات التوفر غير المؤكد.

التحقق: اختبارات استعادة القسم والروابط والتفضيلات، عزل مصادر الأقسام، قارئ
النهدي والأسعار المشطوبة والروابط غير الآمنة والبحث الخالي والعبارات التي
تتضمن تركيزًا. مراجعة أصلية في المتصفح بعرضَي 320 و390 للجوال، والمقارنة
وتبديل الأقسام أثناء البحث وصور المنتجات، وفحص نسخة الكمبيوتر.

# حدود المسؤوليات

- `core`: يعرف عقد البيانات ويدير البحث بالتوازي بمهلة مستقلة لكل متجر. لا يعرف عناوين المتاجر أو شكل ردودها.
- `connectors`: يحوّل بيانات كل متجر إلى Product. لا يعتمد على Next.js أو عناصر العرض.
- `web`: يتحقق من طلب المستخدم ويستدعي الأوركسترا ويعرض النتيجة. لا يحلل ردود المتاجر مباشرة.

## إضافة متجر أو تطويره

داخل مجلد المتجر يمكن إضافة `client.ts` لاتصال HTTP، و`mapper.ts` لتوحيد البيانات، و`types.ts` لأنواع رد المصدر، وملفات اختبارات عند وجود حالات فعلية. لا ننشئ ملفات فارغة قبل الحاجة إليها.

يمرر الموصل AbortSignal لكل طلب شبكة، ويحدد موقع/فرع السعر، ويسجل وقت الجلب. لا يحول السعر المفقود إلى صفر. لا يتضمن الرد الموحّد الكوكيز أو الرموز أو رسائل الخادم الحساسة. تحفظ الأسرار في متغيرات بيئة خاصة بالخادم.

لا يفعّل الموصل إلا بعد التحقق من نتائج حقيقية ورابط المنتج والسعر والتوفّر وسياق الموقع، واختبار التشغيل خارج المتصفح الشخصي. أي اعتماد على متصفح يجب التصريح به وتقييمه في بيئة النشر.

قبل الإتاحة العامة: إضافة تحديد معدل الطلبات والتخزين المؤقت ومراقبة فشل المتاجر، وفق طريقة الوصول الفعلية وشروط كل مصدر. لا يوجد تخزين دائم أو دمج آلي لمنتجات مختلفة في هذا الأساس.

# Knooz Care
Official source: https://knooz-store.com/products?q=Cetaphil (verified 2026-11-13).
Reads public Zid server-rendered search cards, current SAR price (not previous price), stock buttons, product links and store-owned CDN images. Validates store UUID and query-bearing sort links; explicit empty listings are accepted, missing/invalid cards fail. First page only, no customer sessions or delivery address. Beauty category; Makhazen registration was discarded at the user's request.

# Nice One
Official Saudi source: https://niceonesa.com/ar/search?q=Cetaphil, verified 2026-11-13.
Uses public SSR HTML and query-bound ItemList structured data. Cross-checks each offer with its visible card; reads current .font-niceone-bold SAR price, never crossed-out price or untaxed Algolia index price. JSON-LD truncates decimals on some cards (56 vs visible56.95); accepts this specific truncation and retains full visible price. Variant-only cards with no offer are excluded. Products and image URLs must match store path/ID and official product CDN.
First page, no address/session/customer tracking. Source can return unrelated suggestions on unknown queries (observed zzzxxyy999); these are left as source results, not asserted to match the query. Stock follows explicit schema offer. Dynamic public search index was studied but is not called in production because its raw prices exclude storefront tax processing. No public keys are hardcoded or persisted in production.

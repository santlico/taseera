# مقارنة أسعار السوبرماركت

أساس تطبيق ويب باستخدام TypeScript وNext.js وNode.js. هذا المشروع مستقل عن تجربة Reverse API Engineer.

## التشغيل

يتطلب Node.js 20.9 أو أحدث (نوصي Node.js 24).

```powershell
npm install
npm run dev
```

افتح http://localhost:3000. فحص الأنواع: `npm run typecheck`، الاختبارات: `npm test`، بناء الإنتاج: `npm run build`.

## التقسيم

```text

  app/api/search/route.ts         بوابة البحث وتحقق المدخلات

  src/index.ts                    تشغيل المتاجر بالتوازي وعزل الأخطاء والمهلة
  tests/                          اختبارات سلوك التنسيق
packages/connectors/             ربط المتاجر — للخادم فقط
  src/index.ts                    سجل المتاجر
  src/stores/
    othaim/                       العثيم
    danube/                       الدانوب
    sadhan/                       السدحان
    tamimi/                       التميمي
    lulu/                         لولو

```

## مسار البيانات

واجهة العرض ← `GET /api/search?q=chicken&city=الرياض` ← الأوركسترا ← موصل كل متجر ← نتائج موحدة.

كل متجر يرجع حالته منفصلة. لا يعني فشل متجر فشل البحث كله. لا نفرض أن نتائج البحث هي منتجات متطابقة؛ المطابقة الدقيقة وترتيب سعر الوحدة مرحلة لاحقة.

**الحالة الحالية:** جميع موصلات المتاجر معطلة صراحة (`not_configured`). لا توجد أسعار وهمية أو عمليات جلب فعلية بعد. الصفحة الرئيسية مؤقتة وليست التصميم النهائي.

## النشر

يحتاج التطبيق خادم Node.js يدعم Next.js؛ ليس موقعاً ثابتاً فقط. لم يتم نشره أو إثبات وصول الخادم إلى المتاجر بعد. أول معيار قبول للربط: جلب نتائج فعلية من بيئة خادم مستقلة عن جلسة المتصفح الشخصي.
